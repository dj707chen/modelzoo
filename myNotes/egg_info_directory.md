# What is the .egg-info directory in a Python project?

A `.egg-info` directory is metadata generated by Python's packaging tools (setuptools) when you install a package in **editable/development mode** (`pip install -e .`) or build a distribution.

## What it contains

| File | Purpose |
|------|---------|
| `PKG-INFO` | Package metadata (name, version, description, author) |
| `SOURCES.txt` | List of all source files in the package |
| `requires.txt` | Package dependencies |
| `top_level.txt` | Top-level Python packages included |
| `dependency_links.txt` | Dependency URLs (mostly legacy) |
| `entry_points.txt` | CLI scripts and plugin entry points |

## When it's created

- `pip install -e .` — editable install (most common cause)
- `python setup.py develop`
- `python setup.py egg_info`
- Some build steps that invoke setuptools

## Why it exists

It lets Python's import system and tools like `pip` recognize the package without copying files to `site-packages`. The `.egg-info` dir acts as the package's identity — `pip show`, `importlib.metadata`, and dependency resolvers read from it.

## Should you commit it?

**No.** It's generated, machine-specific, and typically listed in `.gitignore`:

```
*.egg-info/
```

In the modelzoo repo, you'd see one at something like `src/cerebras/modelzoo/modelzoo.egg-info/` if the package was installed with `pip install -e .`.
